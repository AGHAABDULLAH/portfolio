# Agha Abdullah - Professional Portfolio

This is the source code for my professional portfolio website, designed to showcase my skills, education, and featured projects as a Data Scientist and Software Engineer.

## Tech Stack
- HTML5
- Tailwind CSS
- FontAwesome (Icons)

## Structure
- `index.html`: The main single-page portfolio layout containing the Hero, About, Skills, Projects, and Contact sections.

## Deployment
This static website is ready to be hosted on **GitHub Pages**, Vercel, or Netlify with zero build configuration required. Simply point the host to the `main` branch.
